# Context evolution heartbeat

The current Codex session is the semantic Observer/Reflector. No scheduler is installed.

- Observer preserves new direct-parent requirements with source, scope, concrete counts and unknown facts.
- Reflector checks active memory and Skills, then saves scoped agreements, credits existing coverage, promotes supported general rules, or rejects unsupported claims.
- `context-memory.py` executes validated merge, replacement, archive, discard and review plans with local transaction history. Start each requested run with `maintain`; only explicitly temporary expiry is automatic. Stable preferences require review rather than deletion because of age.
- `context-evolution.py prepare` still prepares bounded local evidence; old application commands cannot overwrite an initialized memory store.

Read `docs/evolution/POLICY.md` and `references/skills/personal-context-memory.md` for the actual contract. A daily observation / weekly reflection cadence can be configured separately when requested. Raw logs and sensitive memory remain local; the writer cannot change core, permissions or Skills.
