# 假设记录：按本轮阶段填写

记录用于科研决策，不是待贴进论文的贡献段落。保留已有问题 ID；字段可以写在一页说明中，不要求 JSON 或固定篇幅。

## 本轮契约

- 研究对象、权威材料与版本、实际读取范围。
- 要回答的研究问题与当前投稿/交流目标。
- 保留资产、允许调整处、执行权限和本轮终点。
- 关键来源：原始输入、模型输出、参考/评分及其身份；没有的填未知。

## 每个保留候选

- **稳定 ID、假设与处置。** 假设需能被相关证据否定，不先写成已经有效的贡献。
- **现有依据。** 已观察结果、构造例、推论、未知分别说明，附记录 ID 或来源位置。
- **强基线。** 它看到什么、采用什么合理流程；可复用现有最佳结果，不故意弱化。
- **实际变化。** 新信息、标签、模型、训练、表示、决策或预算是什么。
- **同例对照。** 基线和候选如何处理同一输入。输出相同就如实记录；假设性例子标明身份。
- **最近邻。** 真实来源、已核实的方法与边界、目前可主张的差异及尚未核实处。
- **替代解释。** 数据覆盖、局部监督、额外计算、协议差异是否足以解释预期效果。
- **预期价值。** 条件成立时推进什么认识或能力；与目标的距离，不编录用概率。
- **最小核查。** 使用哪些既有材料或最小新对照；结果如何保留、削弱或推翻假设；执行与否。
- **重开条件。** 相比上轮新增了什么；没有实质变化则不以新名称另起候选。

最终先回答本轮有没有筛出值得验证的增量，后给证据和局限。把“流程产出了更明确的研究假设”与“论文已获得新的实证贡献”分开。
