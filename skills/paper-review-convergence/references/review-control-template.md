# 一轮论文审查记录

只在审稿/修订或构思争点需要跨轮次跟踪时采用；沿用项目已有等价记录即可。短讨论可直接记在对话中。所有“已检查”“已关闭”都填写依据，缺失字段标为未知，不填成通过。

## 本轮约定

- 论文身份：
- 本轮目的与交付对象：
- 当前阶段：候选生成 / 纸面筛选 / 经验验证 / 投稿判断；审稿另标实际评审模式。
- 当前材料、版本标识及实读范围：
- 目标要求及来源；尚未约定项：
- 初始主张与边界；本轮发生的主张变动：
- 评审模式：首次发现 / 问题验收 / 变更影响复核。
- 评审责任人与适用独立意见：
- 已完成完整审改周期数、重新评估节点；依据不足时标为未知：

## 问题与处置

每个问题保留以下内容，可用项目现有表格或逐条记录，不要求复制宽表：

- 稳定 ID、首次出现版本、来源及原始意见位置。
- 原文/结果证据、受影响的主张或要求、不处理的影响。
- 类型：已确认缺陷 / 待核查疑问 / 可选增强；关键程度及依据。
- 最小处理方式、验收条件，以及关键核查缺项。
- 状态：未决 / 待验收 / 已解决 / 有依据不采纳 / 可接受局限 / 后续增强。
- 当前处置理由、验收人/方式和当前版本的证据位置。
- 重开记录：原 ID、新证据或相关变化、重开理由；不得覆盖历史。

严重缺陷只有当前有效证据证明已经解决、原判断错误或相关主张已合法撤回且论证链更新时才关闭。作者接受一个风险，不能自动让无效的科学结论成立。

- 稳定问题/候选 ID、研究问题及最强简单基线：

- 同例比较、实际观察 / 逻辑推导 / 待验证收益：
- 保留什么、撤回什么；不受影响的研究问题与其他贡献：
- 最强替代解释、保留/推翻条件及最小关键缺项：
- 判断变化：新证据 / 新推理 / 目标变化 / 上次错误；依据：
- 本轮状态与重开条件；未授权的验证不自动执行：
