# 论文审查收敛

管理一轮论文审查或研究讨论的目标、问题处置和结束条件。论文可以有成立的贡献，同时保留局限与可选改进。新意见和新方案都须说明依据与增量，不能自动延长修改或开启下一轮包装。

## 触发与分工

| 入口 | 执行动作 |
| --- | --- |
| 用户显式调用本 Skill，或问论文何时够好、能否交稿、为什么反复审改仍不能结束 | 有当前稿件与评语时判断本轮状态；只有方法问题时制定规则，不虚构稿件结论 |
| 开始一次实际论文评审，包括独立审稿、投稿前检查和导师用核心结论检查 | 先明确本轮目标和材料范围；已有适用约定则复用，不添加另一轮审稿 |
| 用户按上一轮意见改完要求复核，或同一论文进入后续审改轮次 | 读取本轮记录，先验收已有问题与变更影响，再决定是否需要新评审 |
| 构思中反复推荐又撤回、用户不断追问比简单方法多解决什么，或创新标准发生漂移 | 进入构思收敛模式；先定位同一争点、最强简单基线和判断变化的依据，不立即再造方案 |

普通润色、翻译、排版、算术核对或只讨论写作方案，不因出现论文内容而启动本流程。不能仅因问“够不够”就派遣审稿 Agent。真实独立评审沿用可用的 paper-review-agent 及其授权；本 Skill 不增加委派，也不后台监听或定时运行。

## 构思与贡献讨论的阶段边界

出现方案循环或明确调用本 Skill 管理科研构思时，读取 [构思收敛规则](references/idea-convergence.md)。普通审稿不必加载该分支。

- 先区分本轮在生成候选、筛选纸面增量、等待经验验证，还是判断投稿竞争力；分别回答，不以投稿证据要求否定尚待验证的候选。
- 推荐前，将候选和有相同信息、语义能力的强基线放到同一已有案例中比较；推荐时简明呈现“基线、实际变化、预期行为、证据状态”。没有额外机制时先归入基线或实现选项；没有可区分案例时保留假设，不虚构失败或等用户追问后才筛除。
- 已说明的逻辑等价、未验证的训练收益、已被相关数据反驳的收益，分开处置。撤回只针对失效主张，不自动否定研究问题、资源或其他贡献；案例中决策相同也不能证明两种训练普遍等价。
- 每次改结论指出新证据、新推理、目标变化或上次错误；同一争点沿用 ID。没有改变判断的信息时停止换名和加模块，保留明确的未决命题及重开条件。
- 本轮可以以有条件保留候选、等待关键证据或需要研究取舍结束。用户尚未授权的实验、改稿和研究转向，不因收敛需要自动启动。

## 先固定本轮终点

从现有任务推定并简要记录：

- 论文身份、当前材料路径与版本、实际读取范围，以及本轮是导师讨论、局部修订还是投稿前交付。
- 核心问题和主张、相应证据位置、适用边界；按论文类型选择证据，不把固定模型数、消融形式或写作模板当普遍要求。
- 本轮必查项和未覆盖项。未检查与检查未发现问题分开；局部通过不等于整稿通过。
- 已知目标会议或读者的实质要求。目标不明时保留未约定，不猜会议标准或录用概率。
- 构思模式另记强基线、拟议增量、当前争点及推翻/保留条件；没有实验结果时保留假设身份，不要求先有结果才能讨论。

使用项目已有记录；没有时按需采用 [记录模板](references/review-control-template.md)，保存在当前项目的 work/paper-review/<paper-id>/review-control.md 或现有评审目录。一个活跃审查周期只维护一份当前状态并追加事件；不同论文分开，历史意见保留。短小的一次方法讨论可直接在对话记录，不强制建文件。

## 让意见具有依据和完成条件

每条会改变修改安排的意见，至少给出：原文或证据位置 → 受影响的主张/读者理解/合规要求 → 不处理的实际影响 → 最小处理方式与验收条件。

区分三类，不靠措辞强烈程度或模型投票决定：

- **已确认缺陷**：依据可核对，能说明对本轮主张、测量可信度、贡献定位、必要理解或硬性要求的影响。按影响区分关键阻塞与局部修正。
- **待核查疑问**：怀疑可能重要，但当前材料不足。指出最小核查及其重要性；会影响核心判断的疑问未核清时，不能宣称本轮已通过。
- **可选增强**：扩大适用范围、增加非必要展示或个人措辞偏好。说明收益，可留到后续，不自动升级为交付条件。

“实验不足”“创新性不够”须落到具体主张、缺失的必要证据或已核实的近邻工作。不能只凭搜索片段、没在当前片段看到材料或另一 Agent 的判断宣布缺陷。既有审稿 Skill 的严重性标签也需要上述影响依据，排版偏好不能据此成为科研结论的阻塞。

同一问题沿用 ID，合并重复意见但保留来源；首次评审尽量指出同类问题的影响范围，不逐轮挤出同一类问题。

## 修订后的验收

先核对当前材料与已有问题的验收条件。关闭需要对应证据；同义改写、换一位审稿者或改严重性标签，都不算解决。处理方式可以是补证、修正文义、撤回无支撑主张、有依据地不采纳，或在不破坏核心结论的前提下明确边界。已确认会使核心结论无效的问题，不能仅靠写进局限关闭。

收窄或撤回主张后，重新检查摘要、贡献、实验解释和结论，并判断剩余贡献是否仍有价值、是否适合当前交付目标。此类研究取舍需作者/导师决定时，给出具体选项，不擅自改变研究目标。

后续复核聚焦改动及其影响范围，而非只看修改的句子。问题、方法、指标、关键证据或核心主张改变时扩大到相关论证链；必要时重做相应整体检查，不自动重审无关章节。

已关闭或有理由不采纳的意见，只有出现新证据、相关材料/标准变化或验收失败才重开，并说明依据。原版中后来才发现的真实关键缺陷仍要报告，不能因“不是新改动”排除。只换说法的旧意见不重开。

## 何时结束或转向

结合已约定的范围，给出一个状态：

- **可以结束本轮**：必查项已有可核对结果；已确认的关键缺陷已处理，核心疑问已核清；剩余局限不破坏本轮成立的主张；变更影响检查完成。说明仍未覆盖的范围与可选增强。投稿阶段还需核实贡献定位、目标要求与交付完整性；本轮通过不保证录用。
- **继续修订**：仍有确定且可处理的阻塞，列出问题 ID、最小动作和验收条件。
- **等待关键证据**：缺失材料、核查或独立意见使关键判断无法成立，明确缺什么；构思中保留可检验但未证实的收益假设，停止用改名、加模块或反复改文字替代补证。
- **需要研究取舍**：主张与证据/价值发生冲突，或不同建议互相冲突，给出具体取舍及代价，交还作者判断。

出现连续审改仍无进展、同一问题反复开关、意见互相冲突或研究范围持续扩张时，先诊断审查方式。若无约定，第三个完整审改周期后默认做一次这种评估；已出现征兆时提前评估，不为凑轮次继续审。轮次上限只触发重新判断，不证明论文合格，也不取消已确认缺陷。

结果先说当前状态、依据与剩余关键项。不要用问题数量、模型分数、多模型一致或连续几轮没有新意见代替完成证据。没有新证据或相关变更时，复用当前判断，不自动启动下一轮全稿挑错。

## 权限与接入

在授权范围内记录评语和处置，不自动修改论文、追加实验、外发稿件或维护个人记忆。已有论文评审流程可在开始时读取本 Skill 固定范围，在结果返回后由主智能体执行处置与验收；保持一轮评审一个责任链。
