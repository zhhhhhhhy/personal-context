# 论文评审 Agent

这是主智能体调用的委派 Skill。评审者拥有独立会话，可使用工具和相关个人 Context，向主智能体提供意见。评审者本人只执行评审协议，不再次派出评审者。

## 何时调用

主智能体在准备给出最终科研判断或交付论文成果前，主动检查以下三个节点。满足条件时调用本 Skill 并派遣真实评审子智能体，不等待用户提及审稿、独立评审、子智能体或 Skill。

| 触发点 | 命中条件 | 本轮评审问题 |
| --- | --- | --- |
| 核心结论确定 | 准备确认或否定方法效果、比较优势、贡献成立等将进入论文主要科学结论的判断；已有当前材料可定位 | 当前证据支持什么、能支持到多强，最终表述是否超出证据 |
| 主线实质修改 | 已对研究问题、核心主张、方法、指标或评价口径完成一轮实质调整，形成可评审的新版本；准备交付修改结果 | 受影响的主张、方法和证据是否仍匹配；限定在变化影响的范围 |
| 重要版本交付 | 准备交付完整初稿、给导师讨论的核心研究结论或投稿定稿，内容涉及主要科学主张 | 当前版本有无影响主要结论的重大问题或必须保留的未决项 |

用户明确要求独立审稿，或核对现有材料后仍有会影响主要科研取舍的关键证据冲突时，也按本流程执行。

每轮先明确一个具体评审问题和当前材料。材料及问题没有变化且已有适用的独立意见时复用；多个节点同时命中也只安排一轮。材料、主张或评判口径发生相关变化时，仅重审受影响部分。

普通润色、翻译、排版、直接算术查询、普通进度汇报和单纯复制文件不因包含论文内容而触发。算术问题由主智能体直接核算；据此准备确定主要科学结论时，再检查上述节点。仅讨论修改设想、尚未形成新版本时，不提前触发主线修改后的评审。用户明确禁止委派时遵从；用户要学习自己审查论文时优先采用教学流程。

## 主智能体工作流

开始实际评审前，读取同级 [论文审查收敛](../paper-review-convergence/SKILL.md)，复用或建立本轮目标、主张与证据范围，并确定本轮是首次发现、问题验收还是变更影响复核。结果返回后由主智能体更新问题处置与本轮状态；该接入不增加评审者或审稿轮次。普通文字处理仍沿用前述不触发边界。

1. 阅读 [评审与交接协议](references/reviewer-contract.md)。确定命中的触发点及实际事实、一个评审问题、材料绝对路径和版本、必要项目资料、可写的评审输出目录。材料可以是当前论文、相关章节、结果表及指标定义，或主线修改后的相关新旧段落；能判断本轮问题的局部材料无需补成全文。缺少判断对象或无法定位材料时，先定位当前项目明确的版本，仍无法确定才询问缺项，不虚构评审。
2. 通过真实子智能体工具派遣一名评审者。本环境使用 collaboration.spawn_agent，设置 fork_turns="none"，不复制完整主对话；模型设置沿用当前配置，除非用户另有要求。交接必须包含协议绝对路径、材料、评审问题、Context 根目录和允许的输出位置，并标明当前只做读取回执。
3. 核对评审者返回的回执，确认实际材料、协议版本、Context 路由、可用工具和缺失项。通过后用 collaboration.followup_task 发出正式评审任务。这是主智能体内部的检查，不是要求用户再次批准。先修复错误路径或缩小到有依据的范围；关键材料缺失时不能标为完整评审。
4. 等待并取得真实评审结果。可继续不依赖评审结论的工作，但不能在结果返回前声称评审完成。只有新的证据或重要歧义才安排一次定向澄清；不要为了凑轮次重复评审。
5. 对会改变主结论的严重问题核对原文或原始结果，再决定采纳、暂缓或不采纳并说明理由。按论文审查收敛规则保留稳定问题 ID、最小修复及验收条件；修订后先复核既有问题与变更影响，不因审稿者换说法自动重开全稿评审。向用户报告当前状态、关键意见与下一步，把来源和范围边界保留给主智能体；不机械转贴整份审稿记录。
6. 在任务允许的输出位置保存回执、评审意见和主智能体的处理决定，并在现有记录中说明触发点、命中事实、评审问题及哪些意见改变了最终判断。已有项目输出约定优先；没有约定时使用当前任务的 work/paper-review/。每个材料版本保留独立记录，不覆盖初判；据真实漏触发、选中却未派遣或无新增价值的案例迭代对应入口或流程。

交接要求和返回字段见上述协议。默认是一名真实评审子智能体；本 Skill 明确要求主智能体在上述节点命中时主动委派，即使用户只要求确定结论、完成主线修改或整理重要交付版本，也应执行。

## 运行边界

- 找不到真实子智能体工具时说明该能力不可用；不由主智能体换口吻代审，也不用一次 API 回答冒充独立 Agent。
- 子智能体按个人 Context 索引读取相关资料。个人沟通偏好、已采用的方法和项目事实可以帮助理解任务；旧评语、预期结论和作者期待不能替代论文证据。
- 评审默认读取材料，只在指定位置写评审记录。修改论文、运行实验、外发论文或更新个人 Context，沿用各自任务授权；本 Skill 不额外授予这些权限。权限继承当前会话，角色约束不等于文件系统隔离。
- 子智能体不得递归使用本 Skill 或自行扩大为多评审团。按当前问题选择必要的科研 Skill；不整套加载科研工作流。
- agents/openai.yaml 允许隐式调用。是否选择本 Skill 仍由宿主根据描述和任务判断；允许自动调用不代表每次必定触发，也不代表后台定时运行。
