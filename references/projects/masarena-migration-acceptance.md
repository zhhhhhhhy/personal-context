# AutoFill→MASArena历史迁移验收

这是用户原任务的要求，不是本轮运行通过记录。

1. AutoFill不可用时，MASArena完成数据准备、审计、评测入口检查。
2. 活动代码和配置不依赖AutoFill路径。
3. 迁移数据SHA-256一致。
4. AutoFill保留自动填充产品代码及无关历史项目。
5. 历史来源可留迁移清单，但不能成为运行时依赖。

迁移范围讨论涉及数据生成、人工/模型标注、数据审计、训练数据准备。源对话对“这是否足以分离”“能否跑全部实验”“毕业设计唯一实验环境”的说法仍是提问；不把它们当成已通过结论。当前状态请按匹配版本的迁移清单、代码和运行结果确认。该记录不赋予删除旧目录或重跑实验的权限。
