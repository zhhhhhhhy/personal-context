# 后端经验：按当前任务读取

适用接口与数据模型、数据库/缓存/并发、部署及服务排障。Java、Go等使用技术标签和条目适用条件，维持同一领域入口。本页当前主要连接已有通用工程经验，具体语言或基础设施经验有真实依据后再积累。

| 当前任务 | 经验或工作流入口 | 继续深入的条件 |
|---|---|---|
| 接口与数据模型设计、工程实现 | 实质多步骤任务走[已有工程工作流](../../skills/engineering-project-workflow/SKILL.md)；需求/PRD/模块讨论按[通用方法](work-methods.md)对应任务进入 | 只读当前接口契约和必要模块，不将旧项目架构当默认要求 |
| 数据库、缓存、并发问题 | 按“后端＋实际技术/问题”从[记忆入口](../../contexts/memory/INDEX.md)检索 | 命中后核对范围；没有经验时依据当前项目和技术资料处理，不制造个人长期经验 |
| 接口鉴权、服务部署或运行故障 | 匹配当前排障Skill；属于已有修复模式时读[通用机制修复](../../contexts/memory/items/engineering.general-mechanism-fixes.md) | 需要连接、环境或配置事实时，核对当前项目/主机；历史访问方式不授予新权限 |
| 长任务CLI/API连接故障、睡眠恢复或连续失败 | [分层定位→暂停→受限恢复](../../contexts/memory/items/backend.long-task-connection-recovery.md) | 沿用当前预算和恢复条件；传输可达、真实调用、Core完成及业务正确性分别核查，不照搬旧阈值或执行授权 |
| 修复验证与交付 | [最小充分检查与约定验收](../../contexts/memory/items/validation.scoped-acceptance.md) | 检查当前改动及已约定验收范围，不默认重复全部检查 |

按任务目的归类：模型API作为论文评分工具时走[论文/评估](papers.md)，鉴权、限流、连接或通道故障才属于这里。技术和版本会影响经验适用性，应保留在scope或标签中；不因同属后端而跨语言、跨项目套用条件。
