# 通用工作方法：按当前任务读取

用于任务组织、需求→PRD→模块设计、验证、交接与跨领域可复用方法。领域专属任务优先进入对应领域，本页不要求所有任务经过固定工程流程；所引用条目继续受原scope约束。

| 当前任务 | 经验或工作流入口 | 适用边界 |
|---|---|---|
| 需求澄清、PRD、模块设计与任务规划 | 匹配当前可用规划/设计Skill；实质多步骤工程使用[已有工程工作流](../../skills/engineering-project-workflow/SKILL.md) | 作为任务信号，不新增阶段目录或强制PRD模板；普通讨论不自动变成实施任务 |
| 修复反复出现的流程/路由问题 | [通用机制修复](../../contexts/memory/items/engineering.general-mechanism-fixes.md) | 在该条工程修复范围内使用，不凭单个样例宣称问题普遍解决 |
| 验证、回归和约定验收 | [最小充分检查与约定验收](../../contexts/memory/items/validation.scoped-acceptance.md) | 保留明确验收要求，不把“最小”解释为跳过已约定检查 |
| 工程项目介绍、README与进展交接 | [README中的进展与修复历史](../../contexts/memory/items/engineering.readme-progress-history.md) | 仅在该范围使用；当前进度仍需当前项目材料支持，不用历史摘要替代事实 |
| 子Agent独立复核、与单次API比较 | [复核与判别框架](../skills/agent-review-and-api-evaluation.md) | 按其范围确认角色、共同材料和规则，显式交接相关记忆并核对回执；不自行授权审核或API调用 |
| 已有文档材料编辑、语种/版本选择 | [保留约定风格](../../contexts/memory/items/documents.preserve-style-v2.md)；多稿时读[确认语种与版本](../../contexts/memory/items/documents.resolve-language-version-v2.md) | 原条目分别限定材料类型和多版本场景；论文实质改写另走论文入口 |
| 个性化讲解、陌生工具初用引导 | [按反馈调整深度并分步引导](../../contexts/memory/items/learning.adaptive-guidance.md) | 用于其教学/初用场景，不强制所有工作逐步等待确认 |

同一方法可以由论文、前端或后端指向同一个原条目，不复制正文、不扩张适用范围。新经验通过现有[记忆入口](../../contexts/memory/INDEX.md)按任务关键词检索；归类时保留主领域、必要任务/技术词、来源和例外。项目数量、路径、版本及一次性授权仍存原项目资料。
