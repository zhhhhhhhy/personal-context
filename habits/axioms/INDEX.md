# Baseline Axioms

这些是参考仓库提供的通用起点，当前标记为 `baseline`，仍需要通过真实对话确认。

| ID | 初始原则 | 使用场景 |
|---|---|---|
| B01 | Context 是长期资产，文件优于临时提示 | 设计记忆、文档和工作流时 |
| B02 | AI 是能力放大器，责任仍由人承担 | 委派、自动化和最终交付时 |
| B03 | 结果需要可验证，过程可以保留弹性 | 工程、研究和评测时 |
| B04 | 先隔离资料，再处理，最后验证 | 多来源信息和高风险任务时 |
| B05 | 简单结构优先于过早自动化 | 新建 Context 和工具链时 |
| B06 | 核心规则每次加载，详细 Context 按任务读取 | 研究、代码和写作路由时 |
| B07 | 重复纠正比单次偏好更可能成为长期规则 | 从对话提炼规则时 |
| B08 | 规则必须带证据、范围和更新时间 | 维护、审计和清理时 |

## 晋升条件

低风险经验可按 `docs/evolution/POLICY.md` 自动进入 `habits/learned.md`：需要至少两个独立父对话的直接用户证据、明确范围与例外、去重和冲突检查。单次任务要求继续观察。

本文的 baseline、核心价值观、身份、隐私和权限变更仍需要用户明确决定。自动经验不等于用户确认的公理。
