# SSH入口间歇失败：复用长连接、隔离队列与核对后续接

知识状态：用户在真实排障中要求保持并共享可用SSH通道；相邻日志有存量连接命令成功、新连接认证前拒绝、桥接共享与断线续接的执行记录。本条保留诊断与协作方法，本轮没有连接服务器、复验通道或证明入口问题根治。

当新建SSH连接间歇失败而已有连接仍可用时，先分别判断TCP、协议握手/认证、新建会话和已有通道的命令执行。保留原错误、时间和当前可见日志；不要把每次查询都重建登录、关闭连接，反复经过受限入口。经当前授权确认有可复用通道后，优先使用它做受限查询，心跳和超时沿用当前环境，不照搬历史常数。

多个会话需要共用现有桥接时，先核对其实际接口和接入权限，独立标识每次请求及结果，按队列规则执行。长任务按已有远端任务机制脱离前台，并保存可核对的任务身份，避免占住共享队列。请求排队多时，在当前允许的连接预算内才考虑独立通道，不默认每个会话都新开连接。

共用传输或拆成两条通道，都不等于GPU、文件及后台任务已隔离；仍须明确资源分工、输出目录和并发写入边界。断线或命令超时不能证明远端任务已经停止；恢复后先核对任务/产物与请求状态，不自动重放可能已提交的训练、写文件或其他有副作用命令。

辅助执行来源：同源L1385记录新连接收到Not allowed at this time；L1401/L1429记录原通道ping命令成功；助手L1563/L1669区分共享队列和资源冲突，L1771记录独立通道，L1974报告恢复且未自动重放。它们是当时的日志/汇报，不代表现在仍有这些通道。具体入口限制原因未由外层服务日志确定；容器内权限也不证明能查看外层SSH入口。

## Boundaries

- 只在已有接口确实支持复用且当前任务授权时使用；不开发新桥接、不创建SSH Skill或默认安装组件。
- 不保存主机密码、私钥或访问令牌；原主机、代理端口、队列路径、心跳常数与当前连接状态须现场核对。
- Not allowed at this time、认证前重置或存量连接正常不能单独确定来源惩罚、连接数限制或其他唯一根因。
- 独立通道不隔离服务器资源；共享桥接接入也不授予其他会话新任务权限，本维护不联系来源会话或重跑历史任务。
