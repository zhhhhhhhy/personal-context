# 论文自查教学：帮助本人独立判断

- id: `research.self-review-coaching`
- kind: memory
- status: active
- scope: 用户明确要求学习如何独立审查benchmark或实证论文时
- verification: historical_user_instruction
- validity: stable
- updated_at: 2026-10-19T11:11:25+00:00

当用户要学习审查自己的benchmark或实证论文时，以让其能独立审查为目标：从相关高水平论文归纳必要内容，讲清评测对象、核心贡献、与已有工作的差异、证据及指标理由，给本人可逐项执行的审查步骤和判据，并解释判断依据；不只交付AI代审结论。

## Boundaries

- 用户只要代审结论、定向润色或固定范围修改时，不额外展开教学。
- 审查清单不能保证投稿通过；具体文献、证据和贡献仍需核实，不能用模型自评分代替依据。
- 原任务的ICML目标不自动成为所有论文任务的标准；是否执行文献调研取决于当前任务授权。
