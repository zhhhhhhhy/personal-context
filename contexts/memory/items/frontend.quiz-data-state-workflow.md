知识状态：从一次真实题库前端构建提炼的局部工作流；有历史数据检查和部分浏览器交互证据，不代表当前应用或全部题目已验收。

| 模块 | 输入 → 输出 | 检查或经验 |
|---|---|---|
| 数据与质量整理 | 原资料 → 可用题目、答案/解析及待复核标记 | 区分原解析和补写解析；抽取数量不证明答案语义正确；涉及知识点去重时才读既有题库归并方法 |
| 原题与代表题映射 | 原始题ID、归并组 → 代表题及来源ID映射 | 以稳定标识连接数据和用户状态，保留未入选来源；区分结构覆盖检查与去重语义质量 |
| 页面与状态 | 题目数据、当前练习范围、已掌握/错题状态 → 当前题、反馈、题库计数 | 作答反馈与持久化状态分开处理；切换原题/精选范围时明确来源映射和进度规则，避免按页面序号误认同一题 |
| 交互验收 | 实际页面与测试记录 → 可观察的作答、返回、错题、刷新和重置结果 | 按本次改动检查相应路径，不以脚本通过代替实际交互，也不把测验中产生的记录混作真实学习进度 |

历史证据：同源工具L2838输出来源覆盖与归并统计，浏览器L2866显示答对后计数变化、L2873返回首页后保留状态、L2878显示重置；这些证据只覆盖所见路径。刷新持久化与原题/精选同步另有助手交付汇报，本次未逐项独立重放。

下次只启动项目时走README启动入口；修改数据、状态或交互时才使用本工作流。

## Boundaries

- 只启动或打开页面时不加载题库整理、数据迁移与全部验收历史。
- 此流程不指定未来项目的题量、端口、目录或固定技术栈；旧授权不作为现在清空学习进度或改写题库的许可。
- 稳定ID、映射和状态检查限定于此类数据驱动练习界面；其他界面先核对其数据与状态语义。
- 生成解析和结构覆盖检查都不等于人工核对答案；未检查的路径与语义质量保持待核。
