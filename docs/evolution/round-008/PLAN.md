# Frozen-protocol prospective validation

Objective: test the corrected round-007 router on a different rich uncovered
cohort, measuring both cost and semantic failures without tuning on this cohort.

Allocation: scripts freeze hashes, select metadata, preserve source provenance,
page inputs and validate/apply outputs; parent observes and reflects without a
ledger replay; one fresh independent reviewer checks only issued pages; parent
adjudicates by focused source retrieval; user assesses the reported quality.

Freeze before selection: committed b48ee37 review code and reference, 6,500-token
review pages; unchanged v1 source risk selection and fixed 20% low-risk sample;
existing 80% initial fallback; overlapping message/claim-only risk tags; semantic
issue classes; follow-up only for unchecked matching tags; other stays in its
parent conversation; chained new classes allowed; one fixed outside-class audit
of 10%, minimum 2 and maximum 4, capped by availability. No whole reference arm.
No tag, prompt, seed, threshold or page-limit changes after source reading.

Select using counts and metadata only, suppress titles. Exclude all round-001
through round-007 train/eval selections and prior cited message positions. Prefer
2-3 parents totaling 5,500-8,500 direct-body tokens and multiple task families;
reserve different-family evaluation sources before body reading. Historical
coverage supplements remain explicitly labeled, not presented as virgin logs.
Account for every source message before any candidate lookup. Preserve initial
observations, raw reviewer reports, adjudication, corrections and all read logs.

Compare actual shared/review/follow-up/audit payloads with same-cohort mechanical
whole-packet and legacy-policy reconstructions at the same page limit. Separately
report parent source, candidate, adjudication and core/policy inputs. Include
failed reads or repeated payloads when delivered. Report setup, control and
platform blind spots; payload token counts are not a provider bill.

Accepted findings are repairable observations, not permission to change frozen
rules. With no full reference inventory, semantic recall is unknown: report
sample findings, checked/unchecked scope and residual risk. Any outside-class
finding is evidence against adequate routing, even when fixed locally. Freeze
reflection before evaluation bodies; no default fresh-response comparison when
there is no eligible new rule. No new code tests absent a code/config change.
