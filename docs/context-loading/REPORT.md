# 渐进式入口治理与参考仓库对比

日期：2026-10-15。用户直接授权压缩渐进式披露入口并记录维护规则。此前版本为 `ed1af97`；本次没有从历史对话自动晋升任何个人偏好。

## 结果

入口现在按“短索引 → 当前任务或阶段 → 必要协议或证据”展开。旧内容保留在对应阶段、主题页或历史归档中，三份更新的 Skill 包已同步到本机运行时。

| 入口 | 修改前仓库 | 修改前运行时 | 修改后 |
|---|---:|---:|---:|
| `deep-research/SKILL.md` | 7,064 | 2,032 | **435** |
| `academic-write/SKILL.md` | 1,740 | 1,914 | **369** |
| `notes/candidates.md` | 7,468 | 不适用 | **395** |
| 四份核心合计 | 1,747 | 同仓库 | **1,823** |

单位为 `o200k_base` tokens，计量 UTF-8 文件正文、统一 LF 换行，并按文件相加。它不是当前模型精确计费分词，也不含系统提示、工具定义、Skill 发现目录、聊天历史或工具包装。

研究 Skill 原来存在两套不同版本，因此 7,064→435 同时包含版本归一化和分层，不能宣称为同一流程的纯压缩。更可比的入口变化是当前实际使用的 2,032→435。写作 Skill 的运行时新增边界也已保留，再按任务拆分。

## 分层与保留方式

- **研究**：沿用修改前本机已安装的综述工作流，按范围与检索、综合与质量、写作与交付拆成三份阶段引用。需要进一步判断时再打开该阶段的窄协议。14 个原运行时章节完整保留，仅调整移入引用文件后的相对路径。
- **写作**：按论证与结构、benchmark 与风格、证据与工件、长程会话记录拆分。7 个原运行时章节完整保留，包含运行时新增的“项目状态不能替代有效性证据”等规则。
- **历史候选**：46 条按规划/Skill、文档、研究写作、实验、工程、沟通六个主题拆分。逐条正文、证据、scope、confidence 和状态与拆分前相同；主题页为 891–1,879 tokens。主题拆分不批准候选。
- **精确读取**：已知 ID 时执行 `python scripts/context-evolution.py show-candidate --id C-20261014-035`，只返回目标记录及文件、行号，避免固定行数检索带出邻条。未知 ID 时由主题或关键词定位。
- **历史版本**：旧的 13-agent/seven-mode 研究包完整保存在 `references/skills/legacy/deep-research/`，文件字节校验一致，不进入默认安装或加载路径。其原 monorepo 外部依赖未补齐，所以不宣称历史包可以独立运行。
- **公理索引**：科研任务先选匹配的 Skill；只有研究取舍或长期判断需要时再读 baseline 公理，不为处理固定材料默认增加一层。

## 写入规则与实际检查

核心契约新增短索引原则，详细规则在 [CONTEXT_LOADING.md](../../rules/CONTEXT_LOADING.md)，机器阈值在 [budgets.json](budgets.json)：

| 受控内容 | 上限 |
|---|---:|
| 四份核心合计 | 2,000 tokens |
| 每份 Skill 入口 | 1,000 |
| 历史候选总入口 | 600 |
| 每个候选主题页 | 2,500 |
| learned 入口 | 1,000 |

`python scripts/context-budget.py` 检查当前入口。`scripts/sync-skills.ps1` 在任何运行时复制之前执行这项检查；超预算或缺少计量依赖会停止同步。依赖当前 Python 环境中的 `tiktoken`，不使用字符数代替。

learned 当前为空，未为尚不存在的规则建立复杂存储。维护规则要求它在超过入口预算前先拆分，并同步适配应用与回滚路径。预算检查目前执行在维护和 Skill 同步阶段，不是拦截模型所有读取动作的中间件。

## 验证与质量判断

完成的验证包括：

- 三份修改过的 Skill 格式检查通过；活动包 Markdown 链接能够解析。
- 八项定向证据/写入边界测试通过，包含主题候选 ID 解析、无效 ID 拒绝及单条读取不带出邻条。
- 正常仓库通过七组预算检查；一个实际 PowerShell 同步负例证明超预算在创建运行时目标目录之前被拒绝。
- 全部 46 条候选正文、21 个运行时章节和旧研究包文件的保留检查通过。
- 更新的 research、writing、personal-context 三包分别 11、8、1 个文件，与本机运行时逐文件字节相同。
- 一名隔离评审代理完成三项给定材料的响应测试：研究摘录比较、benchmark 引言重组、候选追溯。它能找到所需流程，保留证据边界与候选状态，没有默认读取全部阶段。试用发现的邻条溢出和公理索引额外读取已作上述修正；修正后的精确读取由定向检查验证。

这是入口大小、资料保留和路由可用性的验证，未测量长期任务准确率或用户满意度。任务推进后可能依次需要多个阶段，入口变短不意味着整项任务累计 token 按相同比例下降；已读内容也不会因文件拆分而自动从当前聊天中清除。
